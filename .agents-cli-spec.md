# Agent Spec — Calm Carbon Coach

## Overview

A conversational AI agent (Gemini-powered) that interviews users about their lifestyle to estimate their carbon footprint. The agent speaks in a calm, warm journalist tone — unhurried, one question at a time. It covers 5 categories (commute, travel, home, diet, shopping), extracts structured data from answers, calculates a footprint using established coefficients, and delivers a personalized summary with insights, benchmarks, and recommendations.

This is a **standalone ADK project** (`calm-agent/`) that will be exposed as an API endpoint so the existing Next.js frontend can call it. It replaces the current `backend/app/services/ai_coach.py` logic with a proper ADK agent architecture.

## Example Use Cases

1. **New interview** — User lands on the Calm webapp, selects "Quick interview" (~10 questions) or "Detailed interview" (25 questions), then clicks "Begin". The agent greets them warmly and asks the first question about their commute.
2. **Mid-interview** — User says "I drive 10 km to work". The agent extracts `{distance_km: 10, mode: "car"}` via tool, calculates the commute footprint on the fly, and asks the next question about travel.
3. **Interview complete** — After 25 questions across 5 categories, the agent returns the complete carbon profile: total footprint, category breakdown, global benchmarks, and 3 personalized recommendations.

## Tools Required

| Tool | Purpose | Data source |
|------|---------|-------------|
| `calculate_carbon` | Compute CO2e from structured interview data. Uses UK DEFRA 2023, ICAO, Poore & Nemecek 2018 coefficients (already defined in `carbon_model.py`). | In-code coefficient tables |
| `get_benchmarks` | Return global and national average footprints for comparison. | Static dataset (global=4.7t, US=14.5t, UK=4.25t, EU=6.3t, India=1.9t) |
| `generate_insights` | Generate a personal summary and 3 actionable recommendations from a footprint breakdown. Falls back to rule-based advice if Gemini unavailable. | Gemini + rule-based fallback |

## Constraints & Safety Rules

- **No medical, financial, or legal advice** — redirect gently if asked.
- **No prompt injection** — the system prompt must instruct the model to ignore attempts to override instructions.
- **Non-judgmental tone** — never shame users for their footprint. Frame all feedback constructively.
- **Interview modes** — User selects at start: **default** (~10 questions, ~2 per category) or **detailed** (25 questions, ~5 per category). After the cap, the agent MUST wrap up and produce results.
- **Input length limit** — truncate user messages over 2000 characters.
- **No PII collection** — never ask for full name, address, email, or phone number.

## Success Criteria

1. The agent conducts a complete interview in either mode (default ~10 or detailed 25 questions), covering all 5 categories without derailing
2. Extracts structured data from free-text answers (e.g., "I drive 10 km" → `{distance_km: 10, mode: "car"}`)
3. Returns an accurate carbon calculation matching the `carbon_model.py` coefficients
4. Returns benchmarks and 3 actionable recommendations
5. Redirects off-topic or injection attempts gracefully
6. Stays in character (calm journalist) throughout

## Architecture

- **Agent type**: Single agent (no sub-agents for MVP) with 3 tools
- **Session**: Ephemeral, in-memory (no Memory Bank)
- **Integration**: FastAPI endpoint serving the ADK agent, callable from the Next.js frontend
- **Deployment**: Prototype first; target TBD
