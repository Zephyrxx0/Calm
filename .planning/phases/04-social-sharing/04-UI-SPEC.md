## Phase 4 Specific Components

### Contribution Graph (GitHub-style)
- **Layout**: 7 columns × 53 rows (365 days + padding)
- **Square size**: 12px × 12px with 2px gaps
- **Aesthetic**: Crayon-drawn borders using OrganicDoodles patterns
- **Color intensity**: 5 levels from muted (#f0f0ed) to accent (#c2856b)
- **Hover states**: Tooltip with date and carbon consciousness level

### Daily Quick Form
- **Layout**: Vertical stack, single column, 6-7 questions maximum
- **Input style**: Radio buttons or select dropdowns for speed
- **Completion time**: Target 30 seconds
- **Progress**: Linear progress bar (not circular)

### Broadsheet Export Layout
- **Dimensions**: 11" × 17" (true broadsheet proportions)
- **Columns**: 3-4 column newspaper layout
- **Typography**: Serif headings (inherited from existing edition), sans body
- **Masthead**: Traditional newspaper banner with "Calm Carbon Report"

### Firebase Auth Integration
- **Modal style**: Centered overlay with backdrop blur
- **Form layout**: Email/password only, minimal profile data
- **Visual treatment**: Matches existing card styling (rounded corners, subtle shadow)
- **Loading states**: Spinner component (already installed)

### Social Share Cards (1200×630)
- **Template**: Universal format for LinkedIn/Twitter/Facebook
- **Content hierarchy**: Logo → Carbon total → Streak count → CTA
- **Background**: Warm off-white with subtle grain texture
- **Branding**: Maintains organic aesthetic with OrganicDoodles elements

## Animation & Interaction

### Streak Contribution Squares
- **Hover**: Scale(1.1) + opacity increase (150ms ease-out)
- **Fill animation**: Stagger from left to right on page load
- **Active state**: Subtle glow effect using existing --ease-fluid timing

### Daily Form Transitions
- **Question progression**: Fade-up animation (existing pattern)
- **Completion**: Success checkmark animation (200ms)
- **Form validation**: Shake animation for errors (300ms)

### Broadsheet Export
- **Generation loading**: Spinner overlay during html-to-image processing
- **Download trigger**: Button disable state with loading spinner
- **Success feedback**: Brief success toast or checkmark

---

## Accessibility

### Contribution Graph
- **Keyboard navigation**: Tab through squares, Enter/Space to view details
- **Screen readers**: Aria-label with date and activity level
- **High contrast**: Ensure 3:1 ratio between intensity levels

### Daily Form
- **Focus management**: Auto-focus next question on completion
- **Error messaging**: Aria-describedby for form validation
- **Touch targets**: 44px minimum for mobile radio buttons

### Firebase Auth
- **Form validation**: Live validation with accessible error messages
- **Password visibility**: Toggle button with proper labeling
- **Loading states**: Aria-live regions for status updates
