| Frontend → Backend API | Firebase JWT tokens in Authorization headers |
| Browser → DOM | User-generated content in form inputs |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|

| T-04-08 | Tampering | Form data | mitigate | Server-side validation, authenticated endpoints only |
| T-04-09 | Info Disclosure | Contribution data | mitigate | Only show user's own data, verify Firebase UID |
