<task type="auto">
  <name>Task 1: Create Ledger API Router</name>
  <files>backend/app/api/ledger.py, backend/tests/test_api_ledger.py</files>
  <action>
    Create a new router for Ledger operations.
    1. Implement `POST /upload/{session_id}` accepting an `UploadFile`. Spool file to a temporary location, call `scan_receipt_or_bill`, and clean up the temp file.
    2. Insert the extracted data as a new `LedgerEntry` linked to `session_id`.
    3. Recalculate the session's total carbon footprint AND category breakdown. The calculation must combine the original Phase 1 footprint estimate with the new `LedgerEntry` impact values for a refined total.
    4. Implement `GET /{session_id}` to retrieve all ledger entries, the recalculated total footprint, and the updated category breakdown for the session.
    5. Ensure proper error handling (e.g., 404 if session doesn't exist).
    6. Write integration tests in `backend/tests/test_api_ledger.py` utilizing FastAPI's TestClient to verify the endpoints, calculations, and data combining logic.
  </action>
  <verify>
    <automated>cd backend && pytest tests/test_api_ledger.py</automated>
  </verify>
  <done>Endpoints handle file uploads, calculate the combined total and breakdown, and pass tests.</done>
</task>
