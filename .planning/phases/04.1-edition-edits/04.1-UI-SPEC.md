## Spacing Scale — Newspaper Context

The newspaper layout uses **physical print units** (inches) rather than pixel-based tokens. This is a deliberate exception to the 8-point pixel scale — justified because the broadsheet renders at physical dimensions (17×11 inches) for export. Internal spacing follows traditional newspaper column conventions.

| Token | Value | Usage |
|-------|-------|-------|
| Column gap | 0.5 in | Between multi-column layout columns |
| Column rule | 1px solid #D4D4CD | Vertical divider between columns |
| Page padding | 0.75 in (horizontal), 0.5 in (vertical) | Inner margins of broadsheet container |
| Masthead spacing | 0.15 in top / 0.1 in bottom | Masthead title vertical rhythm |
| Masthead rule | 2px height, full width, `#2C2C2A` | Thick rule above/below masthead |
| Section margin | 0.3—0.4 in bottom | Spacing between content sections |
| Section label margin | 0.12 in bottom | Label-to-content gap |
| Table cell padding | 3—4px horizontal, 3px vertical | Category table dense spacing |
| Fold crease position | ~50% vertically (5.5 in from top) | Horizontal fold line with gradient + shadow |

**Exceptions:** The newspaper context uses inch-based physical spacing throughout. Pixel values are used only for thin rules (1—2px) and table cell padding (3—4px) where sub-inch precision is needed. This is locked by D-39 and the user's spec sheet Section 1 (layout structure).

Two fonts loaded via `next/font/google` with `display: 'block'` (D-53). The `display: 'block'` setting is critical: `html-to-image` must capture fonts synchronously during export.

| Table header | PT Serif | 9—10px | 600 (SemiBold) | 1.3 | 0.05em |

## Color — Newspaper Context (60/30/10)

The newspaper is inherently **monochrome** — no Calm accent colors, no sage, no warm terracotta. The 60/30/10 split maps to paper/ink/rules rather than traditional UI surfaces.

| Role | Value | Usage |
|------|-------|-------|
| **Dominant (60%)** | Cream-to-ivory gradient: `#FAFAF8` (top) → `#F5F0E8` (bottom) | Newspaper paper background. Applied as CSS `background: linear-gradient(180deg, #FAFAF8 0%, #F5F0E8 100%)` on `.newspaper-broadsheet` |
| **Secondary (30%)** | `#1A1A1A` (headlines, footprint number), `#2C2C2A` (body text) | All ink-colored text. Headlines are slightly richer black; body text is slightly softer for readability at small sizes |
| **Accent (10%)** | `#D4D4CD` (column rules), `#2C2C2A` (masthead rules), `#E5E5E2` (table dotted separators) | Thin rules, borders, and divider lines only. The fold crease shadow uses `rgba(0,0,0,0.06—0.12)` |
| **Muted text** | `#6B6B68` | Dates, source citations, table headers, unit labels |
| **Light muted** | `#9A9A97` | Footer text |
| **Quote accent** | `#C2856B` (left border only) | Pull quote left-border accent — the sole color from the Calm palette that enters the newspaper. Preserved from existing design |

**Accent reserved for:** Masthead rules (top/bottom thick rules), column rules (thin vertical dividers), fold crease shadow gradient, and table separator dots. **Never** applied to text, backgrounds, or interactive elements. The pull quote accent border (`#C2856B`) is the one exception — a tertiary detail.

**There is no destructive color in the newspaper context.** Export and rendering errors are shown in the application shell (Context A), not inside the newspaper.

**Source:** D-45, D-46 (2000 broadsheet era: bright cream, clean print, subtle aging). User spec sheet Section 4 (color/age calibration). The existing `#FAFAF8` gets a warmer gradient partner (`#F5F0E8`) for the vintage paper feel.

## Newspaper Visual Effects Contract

This section is unique to Phase 04.1 — it declares the filter chain that makes the newspaper look like a scan of a printed page. All effects are SVG/CSS filters applied to DOM elements (D-47, D-55).

### Effect Stack (ordered bottom-to-top)

| Layer | Technique | Target Element | CSS/SVG Filter |
|-------|-----------|---------------|----------------|
| 1. Paper grain | `feTurbulence` (type="fractalNoise", baseFrequency 0.4—0.6, numOctaves 3—4) → `feColorMatrix` (luminanceToAlpha, opacity reduction) | `.newspaper-broadsheet` container | `filter: url(#paper-grain)` |
| 2. Cream-to-ivory gradient | CSS `background: linear-gradient(180deg, #FAFAF8 0%, #F5F0E8 100%)` | `.newspaper-broadsheet` | Native CSS, no SVG filter needed |
| 3. Halftone dots on images | `feColorMatrix` (desaturate + contrast boost + threshold for dot simulation) | All `<img>` elements inside newspaper | `filter: url(#halftone-img)` |
| 4. Ink bleed on headlines | `feGaussianBlur` (stdDeviation 0.3—0.5) + `feComponentTransfer` (contrast boost to restore sharpness with slight spread) | `.newspaper-masthead-title`, `.newspaper-headline-title` | `filter: url(#ink-bleed)` |
| 5. Horizontal fold crease | CSS gradient line (semi-transparent dark band) + `box-shadow` (subtle raised edge) | A dedicated `.newspaper-fold` div placed at ~50% vertical | Native CSS gradient + shadow, no SVG filter |
| 6. Edge wear / deckled edge | `feDisplacementMap` (using feTurbulence as input, subtle scale 2—4px) applied to a border-box mask | `.newspaper-broadsheet` outer edge | `filter: url(#edge-wear)` |
| 7. Subtle vignette | CSS `radial-gradient` overlay (transparent center → `rgba(0,0,0,0.03)` edges) | `.newspaper-broadsheet::after` pseudo-element | Native CSS, no SVG filter needed |

**Source:** D-45 (full scan simulation), D-47 (inline SVG/CSS), D-48 (halftone via feColorMatrix), D-49 (grain via feTurbulence + feColorMatrix). Exact filter parameter values (turbulence frequency, stdDeviation, color matrix values) are implementation tuning — agent's discretion per CONTEXT.md.

### Effect Integration Rules

1. **All SVG filters defined in a single `<svg>` element** placed before the broadsheet container in the DOM. Uses `<filter id="...">` definitions referenced by CSS `filter: url(#...)`.
2. **Filters are scoped to `.newspaper-broadsheet` context.** No other page elements are affected.
3. **html-to-image captures all inline SVG filters natively** (D-55). No special handling needed — the existing `toPng` call with `backgroundColor: "#FAFAF8"` remains unchanged.
4. **`prefers-reduced-motion`** does not affect these filters (they are static visual effects, not animations).
5. **`@media print`** must include the SVG element and apply filters. Print stylesheet already targets `.newspaper-broadsheet` at 17×11 landscape.

## Interaction Contract

### Export Flow (unchanged behavior, preserved from existing)

1. User clicks "Download Broadsheet (PNG)" or "Download Broadsheet (PDF)"
2. Loading overlay appears: semi-transparent cream overlay + spinner + "Generating your broadsheet..."
3. `html-to-image` captures `.newspaper-broadsheet` DOM node at 2x pixel ratio
4. PNG: browser download triggered via temporary anchor element
5. PDF: image embedded in jsPDF landscape format, browser download triggered
6. Loading overlay dismisses. On error: red error banner with error message.

### View Mode Toggle (edition page — existing pattern extended)

1. Edition page loads with "Standard View" / "Broadsheet Preview" toggle
2. Broadsheet mode shows `NewspaperLayout` with edition data
3. Toggle between modes — no data re-fetch needed (same data, different render)

### Daily Page Newspaper (new interaction)

1. Authenticated user on `/daily` sees existing tracking interface
2. New "View as Newspaper" button in action bar (or near "Generate Report" link)
3. Clicking reveals NewspaperLayout rendered with daily tracking summary data (streak, recent entries, totals)
4. Toggle back to return to tracking form + contribution graph view

### Share Page Newspaper (new interaction)

1. Visitor opens `/share/[snapshotId]` — currently sees standard summary
2. New "View as Newspaper" button renders NewspaperLayout with snapshot data
3. No export buttons on share page (shared content is view-only) — or limited to viewing, not downloading
