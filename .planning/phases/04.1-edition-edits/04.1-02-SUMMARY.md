# Summary: SVG Filters & Visual Effects

## What Was Built

Implemented the 7-layer vintage newspaper print effect stack on NewspaperLayout:

1. **SVG Filter Definitions** — Hidden `<svg>` element with 4 filters: `#paper-grain` (feTurbulence + feColorMatrix), `#halftone-img` (desaturation + contrast), `#ink-bleed` (blur + sharpen), `#edge-wear` (feTurbulence + feDisplacementMap).

2. **Container Effects** — `.newspaper-broadsheet` uses cream-to-ivory gradient background (`#FAFAF8` → `#F5F0E8`), chained `filter: url(#paper-grain) url(#edge-wear)`, and `position: relative` for vignette pseudo-element.

3. **5-Column Layout** — Updated from 4 to 5 columns in both screen and print media queries. Added responsive breakpoints (≤1200px → 3 cols, ≤768px → 1 col).

4. **Ink Bleed** — Applied `filter: url(#ink-bleed)` to `.newspaper-masthead-title` and `.newspaper-headline-title`.

5. **Fold Crease** — `<div class="newspaper-fold">` between headline and categories with `column-span: all`, thin border-top, and box-shadow crease effect.

6. **Vignette** — `.newspaper-broadsheet::after` pseudo-element with `radial-gradient(ellipse at center, transparent 60%, rgba(0,0,0,0.03) 100%)`.

7. **Halftone Wiring** — `.newspaper-broadsheet img { filter: url(#halftone-img) }` ready for future image elements.
