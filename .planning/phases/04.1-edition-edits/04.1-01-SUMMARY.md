# Summary: Font Setup & Masthead

## What Was Built

Established the typographic foundation for the vintage newspaper broadsheet layout:

1. **Font Loading** — Playfair Display (weight 700) and PT Serif (weights 400, 700) loaded via `next/font/google` with `display: 'block'` for reliable html-to-image export capture. Exposed as `--font-newspaper-headline` and `--font-newspaper-body` CSS variables on the html element.

2. **Masthead Rename** — Changed broadsheet masthead from "Calm Carbon Report" to "The Daily Calm" with a conditional subtitle paragraph (`.newspaper-masthead-subtitle`) rendered when the `subtitle` prop is provided.

3. **Typography Update** — All font-family declarations in NewspaperLayout's `<style jsx global>` now use CSS variables first (with named font + generic serif fallbacks). Headlines/masthead/numbers use `var(--font-newspaper-headline)`, body/captions/footer use `var(--font-newspaper-body)`.

## Key Changes

- `.newspaper-category-table th` font-weight: 600 → 700 (aligns with PT Serif available weights)
- `.newspaper-headline-subtitle`: 16px italic → 14px normal (aligns with UI-SPEC Subhead tier)
